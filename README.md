# youtube

상업적 이용이 허용된 라이선스(CC0, CC BY, CC BY-SA)의 배경음악·효과음을 검색하고 내려받는 정적 사이트입니다.

- 데이터: [Openverse API](https://api.openverse.org) (`license_type=commercial`)
- 서버·API 키 없이 `index.html` 하나로 동작합니다.
- CC BY 계열 음원은 출처 표기가 필수입니다. 사이트의 '출처 표기 복사' 버튼을 사용하세요.
- GitHub Pages로 배포: Settings → Pages → Branch `main` / root.
